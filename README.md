# Agentic-AI-Projects
In this repo we build and deploy scalable agents  

## Learning path

This repository is a hands-on 10-day path for learning to build, evaluate, and deploy agents. Begin with the [Day 1 Email Triage Agent](projects/day-01-email-agent/README.md).

The starter kit is a Windows/VS Code project. Open `projects/day-01-email-agent` in VS Code, run `./setup.ps1` in its PowerShell terminal, configure `.env` and Gmail OAuth credentials as described in its guide, then use **Run and Debug > Day 1: Email agent**. The first version only creates drafts and alerts; it does not send mail.

Each future project should follow the same pattern: a focused README with a beginner lab, a small runnable example, `.vscode` workspace configuration, setup instructions, secret-safe `.gitignore`, and a clear completion checklist.
